# Password resets and sign-in problems

Keywords: password, reset, sign in, log in, login, locked, SSO, single sign-on

- Reset links are valid for 30 minutes and work once. If one has expired, the
  customer requests a new one from the sign-in page with **Forgot password**.
- If no email arrives within 5 minutes, check the spam folder and that the
  address matches the account.
- Accounts that sign in with single sign-on (SSO) cannot reset their password
  here; their company's identity provider administrator resets it.
- After 5 failed attempts an account is locked for 15 minutes.
