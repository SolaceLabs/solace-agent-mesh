# Export invoices as CSV

Keywords: invoice, invoices, export, CSV, download, spreadsheet, billing history

Account owners and billing admins can export invoices as CSV:

1. Open **Settings → Billing → Invoices**.
2. Pick the date range, for example last month.
3. Select **Export**, then **CSV**. The file downloads straight away.

The **Download** button on a single invoice still gives a PDF; CSV export is
only on the invoice list. Users without the billing admin role do not see
**Export**; ask an account owner to grant it under **Settings → Members**.
