# Security Policy

As with any complex system, it is certain that bugs will be found, some of them security-relevant. If you find a security bug please report it privately via email to
[support@solace.com](mailto:support@solace.com). Include the following
information:

- The Agent Mesh version. The Agent Mesh Desktop Application shows the version in its
  About dialog, and the installer filename contains it, for example
  `solace-agent-mesh-2.409.2-desktop-free-macos-apple-silicon.dmg`.
- The steps to reproduce the vulnerability, and its impact.
