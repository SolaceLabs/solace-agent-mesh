# Contributing

Thank you for your interest in Solace Agent Mesh.

This repository does not accept issues, pull requests, or other outside
contributions. Instead, use the following table to find the right place for
your request:

| To | Contact |
|---|---|
| Report a bug | [support@solace.com](mailto:support@solace.com) |
| Report a security vulnerability | [support@solace.com](mailto:support@solace.com). For what to include, see [`SECURITY.md`](SECURITY.md). |
| Request a feature, ask a question, or discuss Agent Mesh with other users | [Solace Community: Solace Agent Mesh](https://community.solace.com/c/solace-agent-mesh) |
| Discuss running Agent Mesh in production | [Book a demo](https://solace.com/agent-mesh-demo/) with a Solace expert, or [contact Solace](https://solace.com/contact/). |
